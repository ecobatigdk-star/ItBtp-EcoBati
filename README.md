# ItBtp-EcoBati
Site web professionnel d’IT BTP Consulting &amp; GDK ECOBATI Architects, dédié à la présentation des services, projets, réalisations et actualités dans les domaines du BTP, de l’architecture et des solutions technologiques. Inclut un espace d’administration connecté à Supabase pour la gestion des contenus, médias et messages.
